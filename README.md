# FreightRail Insight

Freight railway operations, analytics and automated reporting system.

## Project Overview

FreightRail Insight is a mini full-stack railway operations system designed
to monitor freight trains, shipments and operational incidents.

The project combines:

- PostgreSQL database
- Spring Boot REST APIs
- Angular frontend
- Python analytics and reporting
- Excel report generation
- Machine learning based delay-risk analysis
- Docker containerization
- Selenium UI testing
- Jenkins CI/CD

## Main Features

- Freight train management
- Freight shipment tracking
- Train delay monitoring
- Operational incident management
- Railway analytics dashboard
- Automated Excel reports
- Freight delay-risk analysis
- Automated UI testing
- Docker-based deployment
- Jenkins build and test pipeline

## Technology Stack

| Layer | Technology |
|---|---|
| Database | PostgreSQL |
| Backend | Spring Boot / Java |
| Frontend | Angular / Tailwind CSS |
| Analytics | Python / pandas |
| ML | Python / scikit-learn |

| CI/CD | Jenkins |
